# Global Rules

This folder contains system-wide conventions, guides, and briefing documents that apply to all projects in your Workspace.

## Contents

- **[STYLE-GUIDE.md](STYLE-GUIDE.md)**: Code style and formatting conventions
- **[TASK-WORKFLOWS.md](TASK-WORKFLOWS.md)**: Standard process for planning, implementing, and completing tasks
- **[BRIEFING.md](BRIEFING.md)**: Long-lived context and instructions for your AI assistant

## How to Use

1. **Reference these docs** in all projects to maintain consistency
2. **Update as needed** when you establish new conventions
3. **Share with team** members if collaborating
4. **Review periodically** to ensure they still reflect current practices

## Quick Reference

- **Style**: Follow conventions in STYLE-GUIDE.md for all code
- **Workflow**: Use TASK-WORKFLOWS.md to structure project work
- **Assistant**: Keep BRIEFING.md updated for better AI assistance
