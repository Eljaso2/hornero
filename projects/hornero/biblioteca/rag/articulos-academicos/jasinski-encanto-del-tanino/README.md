# Jasinski — El encanto del tanino

## Estado

🔴 **Sin PDF/MD fuente en el repositorio**

Los chunks de este libro fueron extraídos de un PDF original que no está almacenado en el proyecto (por derechos de autor de Prometeo Libros).

## Contenido disponible

- `jasinski-encanto-del-tanino.chunks.json` — 161 chunks RAG
- Chunks curados manuales en `kb_data.py` (IDs `kb-jasinski-*`): 5 chunks temáticos sobre La Forestal

## Referencia

> Jasinski, A. (2023). *El encanto del tanino*. Prometeo Libros. ISBN 978-987-816-561-5.

## Si se obtiene el PDF

1. Colocar el PDF en esta carpeta como `jasinski-encanto-del-tanino.pdf`
2. Ejecutar `python3 backend/scripts/pdf_to_chunks.py jasinski-encanto-del-tanino.pdf`
3. Los nuevos chunks reemplazarán los existentes automáticamente
