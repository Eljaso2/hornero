Digital sovereignty · the six links

Who controls the AI value chain?

Every AI system is a chain of six links. Dependence means someone else owns them all. Sovereignty means the organization holds the decisive ones — and knows exactly where it still depends.

The stack

Built from parts a union can own

No proprietary black boxes in the critical path. Everything here can be self-hosted, audited, and moved.

Interface
Progressive Web App — native Web Components, Service Worker (offline), installs without any app store
Frontend host
Static hosting — no tracking SDKs, no ad tech, no profiling
Backend
FastAPI proxy — rate-limited, origin-locked; the device never holds keys
Library / RAG
SQLite + retrieval — exact-article match · TF-IDF · LLM query expansion · multi-tenant
Language model
Non-US LLM via an Anthropic-compatible API — swappable, grounded, told to cite and never invent
Voice / multimodal
Speech-to-text — so a worker can ask by voice or photo, not only by typing
Notifications
Web Push — the union reaches its members directly, no intermediary platform
Governance
The union — owns the data, the rules, the corpus, and the on/off switch
