# Feedback

Carpeta para poner screenshots con problemas y textos de conversaciones para corregir.

## Cómo usar

1. **Screenshots**: Arrastrá los PNG/JPG directamente acá
2. **Textos de conversaciones**: Pegá el texto en un archivo `.md` o `.txt`
3. **Nomenclatura sugerida**:
   - `bug-<descripción-corta>.png` — para capturas de pantalla con bugs
   - `fix-<descripción-corta>.md` — para problemas descritos en texto
   - `chat-<tema>.txt` — para transcripciones de conversaciones

Cuando me digas "revisá feedback", voy a leer lo que haya acá y corregir lo que corresponda.
