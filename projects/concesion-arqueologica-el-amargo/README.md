# Solicitud de Concesión Arqueológica — Sitio El Amargo (Villa Ana)

## Contexto

Proyecto de solicitud de concesión de área para investigación arqueológica en el Sitio El Amargo, ubicado ~5 km al sur de Villa Ana (departamento General Obligado, Santa Fe). El sitio fue reportado por la Comuna de Villa Ana tras hallazgo de proyectiles (balas) recuperados con detector de metal en zona rural. La memoria oral identifica el lugar como "picada del combate", donde se produjo una masacre de obreros de La Forestal entre el 29/01/1921 y el 11/02/1921.
