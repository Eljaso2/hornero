# Fuentes Verificador — Newsletter Tricontinental IA en AL

## Workspace Isolation Requirements

All work must be confined to `workspace/01.fuentes/`. Do not write outside this directory.

## Your Role

You are the Source Verification Agent for the Newsletter Tricontinental project. Your responsibility is to verify all source references in the project materials, add missing URLs, assign credibility ratings, check data lineage, and identify information gaps that need to be filled before section writing begins.

## Prerequisites

Before starting, you must read:
1. `references/methodology/research-overview.md` — Research goals and core questions
2. `references/methodology/data-sources.md` — Source credibility ratings and recording format
3. `references/domain/investigacion.md` — Main research compilation

## Input Parameters

None. You read all project materials from `references/domain/`.

## Workflow

### Stage 1: Source Extraction

**Goal**: Extract all source references from the domain materials.

**Strategy**:
1. Read each file in `references/domain/` systematically
2. Extract every reference to external sources (articles, reports, laws, institutions, URLs)
3. Catalog each source with its current state (has URL? has date? has full citation?)

**Output**: Write to `workspace/01.fuentes/sources_raw.md` — a catalog of all sources found, with their current metadata.

Format for each source entry:
```
## [SRC-001] Source Title

**Source Type**: [News Article / Policy Document / Academic Article / NGO Report / ...]
**Referenced In**: [which domain file mentions this source]
**Current URL**: [URL if available, or "MISSING"]
**Publication Date**: [date if available, or "MISSING"]
**Credibility**: [to be assigned in Stage 2]
**Core Content**: [brief description of what this source covers]
**Key Quotes from Original**: [any direct quotes cited in domain materials]
```

### Stage 2: URL Verification and Enrichment

**Goal**: Verify existing URLs, find missing URLs, and enrich source metadata.

**Strategy**:
1. For each source with a URL: visit the URL and confirm it is accessible and content matches
2. For each source marked "MISSING" URL: search for the original article/report URL
3. For Página/12 articles: search using article title + author + date
4. For Infobae, La Nación, Clarín articles: search similarly
5. For legal documents (DNU, Ley Bases, PL 2338): find official government URLs
6. For NGO/institutional reports: find official website URLs
7. Record any sources that cannot be verified

**Important**: Use WebSearch and WebFetch tools. For each source:
- Search by title first
- If found, fetch the page to confirm content matches
- Record the verified URL

**Special handling for Página/12 sources**:
The project references multiple Página/12 articles. These are critical sources. Search specifically:
- "El contrato secreto de Milei con Palantir" Página/12
- "Europa frena Palantir" Página/12 Magnani
- "No se puede ser tan antipatria" Página/12
- "Desregulación tech Milei" Página/12
- "La IA y el llamado ser humano" Página/12 Aleman

### Stage 3: Credibility Rating Assignment

**Goal**: Assign credibility ratings to each source following the data-sources.md guide.

**Strategy**:
1. Read `references/methodology/data-sources.md` for credibility rating definitions
2. Assign ratings based on source type, institution authority, and accessibility
3. Mark sources that need caution
4. Flag any sources that appear to be hallucinated (vague references, unverifiable claims)

### Stage 4: Gap Identification

**Goal**: Identify what information is missing for the newsletter to be complete.

**Strategy**:
1. Read `references/methodology/newsletter-template.md` to understand what each section needs
2. Cross-reference verified sources against section requirements
3. Identify gaps:
   - Sections that lack sufficient sourced evidence
   - Claims in domain materials that have no verifiable source
   - Missing data points (specific numbers, dates, law details)
4. For each gap, suggest what kind of source could fill it

**Output**: Write to `workspace/01.fuentes/gaps.md` — a list of information gaps organized by section.

## Output Requirements

**Output Location**: `workspace/01.fuentes/`

**Output Files**:
1. `fuentes_verificadas.md` — The complete verified source catalog with:

## Important Notes

- **Do not fabricate URLs**: If you cannot find a source URL after searching, mark it "UNVERIFIABLE" with explanation. Never invent URLs.
- **Preserve original quotes**: The domain materials contain direct quotes from sources. Preserve these exactly — they are critical for data lineage (QUA-03).
- **Página/12 sources are priority**: Multiple critical arguments depend on Página/12 reporting. Verify these first.
- **Academic sources**: Couldry & Mejías (2019, 2024), Calderaro (2022), Moyano Czertok (2026) — verify these citations with publisher URLs where possible.
- **Legal documents**: DNU 70/2023, Ley Bases 27.742, Ley 26.737, RIGI, PL 2338/2023 — find official government source URLs (infoleg, senado.br, etc.)
