## Workflow

### Stage 1: Context Building

**Goal**: Understand what this section needs to accomplish.

**Strategy**:
1. Read the newsletter-template.md section specification for your SECCION_ID
2. Read the verified sources catalog — identify sources relevant to your section
3. Read the domain files listed for your section in the table above
4. Identify the 3-5 key arguments this section must make
5. Identify the hooks/phrases that anchor the section

### Stage 2: Argument Construction

**Goal**: Build the argument structure for this section.

**Strategy**:
1. For each key argument, identify:
   - What claim you are making
   - What source(s) support it (use SRC-XXX citations)
   - What evidence (data, quotes, examples) you will use
2. Ensure each argument connects to the overall newsletter thesis: "IA en América Latina no es solo una cuestión tecnológica: es una cuestión de soberanía"
3. Ensure each argument connects to the section's sub-thesis (defined in newsletter-template.md)
4. Write a brief argument outline (not the full text) — just claim + source + evidence for each point

### Stage 3: Section Writing

**Goal**: Write the complete section text.

**Strategy**:
1. Open with a hook — the phrase defined in newsletter-template.md for this section
2. Develop each argument in 2-3 paragraphs
3. Use direct quotes from sources where powerful (quote block format `>`)
4. Cite every claim with SRC-XXX format (e.g., "Según [SRC-004], Milei y Thiel se reunieron...")
5. Use the comparison tables from modelo-dato-exportador.md where they strengthen the argument
6. End each section with a transition that leads into the next section
7. Target length: 800-1200 words per section

**Writing Style** (from quality-standards.md — you must read and follow it):
- **Voice**: Autoritative but committed — "militante-académico". Not neutral observation, but politically engaged analysis backed by evidence.
- **Tone**: High certainty on political claims that are well-sourced; scholarly caution where evidence is incomplete.
- **Language**: Spanish. Precise, muscular sentences. Avoid academic jargon; use vivid political language.
- **Audience**: Tricontinental readers — Latin American left, union organizers, social movements, academics.
- **Forbidden**: "perhaps", "might", neoliberal euphemisms ("innovation", "disruption" without critique). Do not hedge on sovereignty claims that are well-sourced.

### Stage 4: Self-Quality Check

**Goal**: Verify your section meets all quality standards before output.

**Strategy**:
1. Check every claim has a SRC-XXX citation
2. Check no claim is unsupported (no "widely known", "reportedly" without source)
3. Check format: starts with ## (not #), blank lines around lists/quotes, no level-1 headings
4. Check length: 800-1200 words
5. Check transitions: section ends connecting to next section
6. Check voice: is it militante-académico? Not dry academic, not propaganda
7. If any check fails, revise before writing output file

## Important Notes

- **Do not fabricate sources**: If a claim lacks a verified source, either find one or omit the claim. Never invent citations.
- **Do not lower completion criteria**: If you cannot meet word count or citation requirements, report the issue rather than producing substandard output.
- **Preserve the political edge**: This is a Tricontinental newsletter — it takes a position. "Neutral" analysis that obscures power relations is worse than committed analysis that names them.
- **Use the hooks**: Each section has a suggested hook phrase. Use it as your opening or central metaphor.
- **Comparative tables**: The modelo-dato-exportador.md contains a powerful comparison table (Agroexportador vs Dato-Exportador). Adapt it, don't copy it verbatim — make it flow within the narrative.
- **Moyano Czertok quotes**: The Moyano Czertok file contains several powerful direct quotes. Use them — they are the juridical backbone of the sovereignty argument.
