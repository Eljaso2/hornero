# Workflow — Solicitud de Concesión Arqueológica Sitio El Amargo

## Fase 1: Preparación (17/06–30/06/2026)

### 1.1 Confirmar equipo y titular
- [ ] Definir titular del proyecto (persona principal responsable)
- [ ] Confirmar integrantes del equipo y roles específicos
- [ ] Recopilar CVs abreviados (titular: máx. 8 págs.; equipo: máx. 2 págs. c/u)
- [ ] Obtener firmas de conformidad de cada integrante

### 1.2 Delimitar área solicitada
- [ ] Definir polígono del área con vértices georreferenciados (decimal negativo)
- [ ] Base: coordenadas del hallazgo (-28.493474, -59.613147)
- [ ] Ampliar el área para cubrir contexto arqueológico del sitio
- [ ] Verificar que el área está dentro de límites provinciales
- [ ] Generar mapa/cartografía del área

### 1.3 Verificar territorios indígenas
- [ ] Consultar registro del Instituto Provincial de Aborígenes Santafesinos (IPAS)
- [ ] Redactar nota indicando si el área comprende territorios de comunidades originarias

### 1.4 Definir depósito de materiales
- [ ] Identificar museo más cercano con condiciones adecuadas
- [ ] Establecer depósito temporario y tentativamente definitivo
- [ ] Verificar que La Forestal puede tener materiales en guarda hasta 2 años post-concesión

## Fase 2: Redacción de la solicitud (01/07–15/07/2026)

### 2.1 Secciones obligatorias (Anexo 1)
- [ ] **Área solicitada** — Polígono georreferenciado con todos los vértices
- [ ] **Objetivos** — Especificar objetivos y temas de investigación (teóricos y metodológicos)
- [ ] **Cronología** — Recorte temporal; protocolo para hallazgos fuera del período
- [ ] **Metodología** — Métodos y técnicas de campo y laboratorio
- [ ] **Bibliografía de referencia**
- [ ] **Depósito de materiales** — Temporario y definitivo
- [ ] **Proyectos e instituciones** — Marco institucional
- [ ] **CV abreviado del titular** — Máx. 8 págs., firmado
- [ ] **Nómina del equipo** — Rol + CV (máx. 2 págs.) + firma conformidad
- [ ] **Nota IPAS** — Territorios indígenas

### 2.2 Objetivos (basados en propuesta original)
- [ ] Objetivo 1: Indagar en el acontecimiento histórico de comienzos de 1921
- [ ] Objetivo 2: Relevar y registrar arqueológicamente el campo El Amargo
- [ ] Objetivo 3: Analizar objetos recuperados (identificación, clasificación, contexto)
- [ ] Objetivo 4: Evaluar estrategias de puesta en valor del patrimonio cultural
- [ ] Objetivo 5: Promover preservación, interpretación y apropiación comunitaria

## Fase 3: Presentación online (16/07–31/07/2026)

⚠️ **2026: Trámite EXCLUSIVAMENTE ONLINE** — no hay copia papel.

### 3.1 Trámite online
- [ ] Completar trámite en: https://www.santafe.gob.ar/gestionesciudadanas/tramite/69e226144b312247bcb9ae89
- [ ] Adjuntar proyecto completo (según Anexo 1) en formato digital
- [ ] Adjuntar CVs con firmas (digitalizadas)
- [ ] Declarar si el área incluye zonas de comunidades originarias

### 3.2 Verificación final
- [ ] Confirmar recepción por correo: patrimoniocultural@santafe.gov.ar
- [ ] Guardar comprobante de trámite online

## Fase 4: Post-concesión (si se otorga)

### 4.1 Informes (según modalidad elegida)
- [ ] Informes parciales anuales (bianual/trianual)
- [ ] Informe final (todos los casos)
- [ ] Fichas Únicas de Registro (FUR) de colecciones y sitios

### 4.2 Obligaciones
- [ ] Coordinar con museos locales (Ley 12.955)
- [ ] Comunicar hallazgos de otros períodos cronológicos
- [ ] Notificar al municipio sobre la concesión otorgada

## Notas importantes

- Si el primer año (bianual/trianual) no se presenta informe → llamado de atención de la autoridad
- Faltante de informes o FUR → impedimento para nuevas concesiones
- Se puede renunciar a la concesión antes del tiempo solicitado con justa causa
- La concesión y datos del proyecto serán publicados en la web del gobierno provincial
